# AI LLM BERT

BERT 기반 자연어 처리 모델과 AI 연산 최적화 기법을 연구하고 구현한 프로젝트를 정리한 GitHub 저장소입니다.

BERT 모델의 학습 및 성능 평가, GLUE Benchmark를 활용한 검증, CORDIC 기반 연산 최적화, KAN(Kolmogorov-Arnold Network) 관련 실험 코드를 포함하고 있습니다.

### 주요 내용
- **BERT**: 자연어 처리 모델 구현 및 성능 분석
- **GLUE Benchmark**: BERT 모델의 성능 평가 및 검증
- **CORDIC**: AI 모델의 연산 효율 개선을 위한 알고리즘 적용
- **KAN**: 신경망 구조 및 연산 방식에 관한 실험

### 개발 환경
- Python
- PyTorch
- Google Colab / Jupyter Notebook

본 저장소는 AI 모델의 알고리즘 분석부터 연산 최적화 및 성능 검증까지의 연구 과정을 기록하기 위해 구성되었습니다.
